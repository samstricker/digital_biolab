# Digital BioLab

This repository contains the code for the Digital BioLab project, which aims to create a digital version where bioprocesses can be simulated, to test optimization and control strategies in-silico before applying them in the real world.

## Mammalian Cell Culture Simulation
The mammalian cell culture simulation module `dbiolab.mammalian_cellculture_simulation` provides a framework for simulating CHO cell bioprocesses, including growth, product formation, and purity dynamics. The model tries to incorporate key biological and process parameters to enable realistic simulations of cell culture performance under various conditions.
